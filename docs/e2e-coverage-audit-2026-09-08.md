# Аудит пользовательских сценариев и E2E-покрытия

Дата: 2026-09-08. Основа: текущая рабочая копия, HEAD `2fc38cf`, включая незакоммиченные изменения публичной пагинации. Код приложения и существующие тесты не изменялись.

**Вывод: не все реализованные пользовательские сценарии покрыты браузерными E2E-тестами.** Ниже перечислены 57 групп недостающих проверок: 11 с приоритетом P0, 40 — P1 и 6 — P2, включая непроверенные ветки частично покрытых функций. Это перечень для планирования тестов, а не процент покрытия и не утверждение о наличии 57 ошибок.

Проверены все 17 шаблонов маршрутов в `Components/Pages`, используемые ими компоненты, клиентские обработчики запросов и JavaScript, все тесты проекта `GaifulinLab.E2E.Tests`. Для разграничения уровней покрытия дополнительно просмотрены API- и unit-тесты. Покрытием считается явная проверка результата сценария; подготовка данных, вызов `GotoAsync` или наличие кнопки сами по себе не подтверждают весь путь пользователя.

Это статический аудит исходников. Тесты и сайт не запускались; актуальная проходимость тестов не подтверждена. Для составления списка пробелов запуск не требуется. По [README E2E](../tests/GaifulinLab.E2E.Tests/README.md) полный прогон использует обычную development-БД, применяет миграции и оставляет тестовые данные.

## Инвентаризация маршрутов

«Частично» означает, что есть проверки конкретной ветки, но остаются сценарии из списка ниже. Посещение страницы при подготовке теста не считается полноценной проверкой страницы.

| Маршрут | Браузерное покрытие |
| --- | --- |
| `/` | Нет проверок главной страницы и её блоков |
| `/articles` | Частично: положительный результат `topic+tag` |
| `/archive` | Нет |
| `/topics` | Частично: название и описание одной темы |
| `/series` | Нет |
| `/tags` | Частично: наличие одного тега |
| `/{LanguageCode}/series/{Slug}` | Частично: порядок EN-статей после замены удалённой |
| `/{LanguageCode}/articles/{Slug}` | Частично: EN-чтение, картинка, просмотр, PDF, недоступность после unpublish/delete |
| `/search` | Нет; сама страница пока заглушка |
| `/about` | Нет |
| `/not-found` и неизвестные маршруты | Нет; Article not found — другая ветка |
| `/register` | Частично: успешная регистрация |
| `/admin/login` | Частично: успешный вход |
| `/admin/articles` | Частично: заголовок, переход New article и возврат после удаления |
| `/admin/articles/new` | Частично: создание, публикация, изображение, один случай валидации и отдельные проверки layout |
| `/admin/articles/{ArticleId:guid}` | Частично: lifecycle, конфликт Save my draft, освобождение позиции серии |
| `/admin/profile` | Нет |

## Недостающие сценарии

Приоритеты: **P0** — доступ и сохранность пользовательских данных; **P1** — основные функции; **P2** — удобство, оформление и дополнительные ветки. Приоритеты предложены по риску. Каждая строка — группа проверок; варианты внутри строки удобно параметризовать. Ожидаемый результат описывает, что должен доказать будущий тест, а не подтверждённое поведение текущей версии.

## Границы реализованного функционала

- `/search` всегда рендерит `EmptyPublicPage`; поля поиска, запроса и результатов нет. Функциональный поиск — будущая возможность, а не существующий сценарий без теста.
- Создания/редактирования/удаления самих тем и серий через UI нет. [AdminTaxonomyController](../src/GaifulinLab.Api/Controllers/AdminTaxonomyController.cs) предоставляет только GET. Проверять следует назначение существующих сущностей статье; создание taxonomy при подготовке теста допустимо отдельно от UI-пути.
- Публичные каталоги сейчас используют EN; EN/RU реализованы в редакторе и адресах статей/серий. Глобальный переключатель языка сайта отсутствует.
- Не обнаружены пользовательские функции комментариев, лайков, подписки, восстановления пароля, смены пароля/email, управления пользователями и восстановления удалённой статьи. Они не добавлены в пробелы текущего E2E-покрытия.
- Не обнаружена защита от ухода с несохранённым новым черновиком. Требование предупреждать/восстанавливать такой черновик сначала нужно определить как продуктовый сценарий; оно не выдается здесь за существующую реализованную функцию.

## Порядок расширения набора

1. Доступ и сохранность: AUTH-04/05/07, EDIT-01–04, EDIT-09/10/12, CONTENT-02.
2. Основные пути без покрытия: профиль, пагинация/фильтры, RU и переводы, удаление из списка, обновление публичных каталогов после lifecycle.
3. Ошибки и восстановление: формы, preview/upload/PDF, пустые состояния и недоступность API.
4. Мобильные сценарии, навигация, настройки оформления и клавиатурное управление.

Для каждого положительного E2E проверять результат после reload или в независимом читательском контексте, а не только toast/статус редактора. Для отрицательных фильтров и прав доступа обязательно включать посторонние данные. Ошибки сети можно воспроизводить перехватом конкретного запроса в браузере; такие проверки UI не заменяют отдельные сквозные проверки с реальным API. Полный перебор сочетаний браузеров, экранов и состояний не предполагается: сначала нужен основной браузерный путь каждого сценария и отдельные проверки мобильных отличий.
